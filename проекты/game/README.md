# Spaceships

2D космический шутер на pygame. Игрок уклоняется от метеоритов и уничтожает их пулями. Метеориты летят волнами, каждая волна быстрее и многочисленнее предыдущей. Пули имеют шанс крита по алгоритму PRD.

## Зависимости

Python 3.10+, pygame 2.x

pip install pygame

## Запуск

cd game
python main.py

## Управление

| Клавиша | Действие |
|---|---|
| W / S | Движение вверх / вниз |
| A / D | Движение влево / вправо |
| Space | Выстрел |
| P / Esc | Пауза |

## Структура

src/
  config/       - настройки и конфиг
  entities/     - bullet, meteor, player (MVC)
  map.py      - фона
  menu.py    - главное меню
  ui.py          - HUD и UI
assets/        - спрайты, аудио, фоны
